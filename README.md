# VAL 小戰績 v3

特戰英豪個人戰績工具。可以看自己的詳細戰績（沒開遊戲也行）、對戰中隊友的段位，還有 Lineup 影片庫。

## 需要
- Windows 電腦
- Python 3.9 ~ 3.13（安裝時勾選「Add Python to PATH」）
- Windows 10/11 內建的 Edge WebView2（一般都有）

## 使用（桌面 App）
1. **第一次**：雙擊「1_install.bat」（安裝 App 視窗用的 pywebview，只要一次）
2. 雙擊「3_demo.bat」→ 用假資料看看 App
3. 開遊戲後，雙擊「2_start.bat」→ 按左下角「同步戰績」

想要一個 .exe：雙擊「4_build_exe.bat」，完成後資料夾會多一個「ValTracker.exe」（有吉祥物圖示），
之後雙擊它就能開，可以右鍵 → 傳送到 → 桌面（建立捷徑）。打包好的 exe 不需要 Python 也能跑。

關閉 App 視窗就會完全結束。如果 App 視窗開不起來，會自動改用瀏覽器開，
錯誤紀錄在 `%USERPROFILE%\.valtracker\error.log`。

指令版：`python app.py`（App）、`python app.py --demo`（展示）、`python app.py --browser`（用瀏覽器開）

## v3 新功能
- **2D 回放**：對局紀錄點開一場 → 小地圖上看每次擊殺當下大家站哪，可以逐回合、逐殺、自動播放
- **地圖熱點**：特務・地圖頁點一張地圖 → 看你最常死在哪、最常在哪殺人（可分攻／守）
- **我的回顧**：像年度回顧的直式卡片，可以存成圖片（存在「圖片\VAL小戰績」）
- **上分預測**：照最近 RR 變化估計再幾場升階
- **打完自動同步**：回到大廳後自動抓這場戰績，跳出結算卡片
- **開特戰時自動打開 App**：設定頁打開開關即可
- **對戰中看敵方**：進入對戰後顯示敵方牌位、最高牌位、勝率，以及我方 vs 敵方平均牌位
- **精選 lineup**：Lineup 頁內建 60 部影片，依特務 × 地圖分類
- **檢查更新**：設定頁填 GitHub「帳號/repo」後一鍵更新
- **最佳拍檔名稱**：從你的好友列表補上名字
- **新特務圖片**：官方資料沒有的特務會顯示佔位頭像；可以把圖片放到 `%USERPROFILE%\.valtracker\agents`（例如 `靜.png`）

第一次開 v3 會重新下載最近的對局（為了加上位置資料），之後就不用。

## 沒開遊戲也能查（選用）
1. 到 https://api.henrikdev.xyz/dashboard/ 登入，產生免費 API key
2. App →「設定」→ 貼上 key；如果沒開過遊戲，再填 Riot ID（名字#TAG）
3. 按「同步戰績」。App 會先試遊戲，遊戲沒開就改用 HenrikDev

抓過的對局都存在 `%USERPROFILE%\.valtracker`，之後沒網路也能看。

## 頁面
| 頁面 | 內容 |
|---|---|
| 總覽 | 牌位、RR 走勢、能力雷達、10 項數據（含 KAST、DDΔ、首殺首死、殘局）、近 20 場、成就徽章、狀態提醒、吉祥物講評 |
| 對局紀錄 | 每場戰績 + ACE/4K/殘局/MVP 標籤；點開看回合時間軸和計分板 |
| 特務・地圖・武器 | 每個特務的表現、每張地圖的攻守勝率和推薦特務、武器擊殺榜 |
| 習慣分析 | 時段熱力圖、每日勝率、攻守、殘局 1v1~1v5、多殺、最佳拍檔、單排 vs 組隊、交易擊殺、經濟、技能使用 |
| 對戰中 | 隊友特務／牌位／最高牌位／勝率，加上這張地圖＋你的特務的 lineup |
| Lineup 影片庫 | 每個特務 × 地圖的 YouTube / Tracker.gg 連結，收藏自己的影片（對戰中自動帶出） |
| 設定 | API key、Riot ID、同步場數 |

YouTube Data API key（選填）：填了之後 Lineup 頁可以直接在 App 裡搜尋和播放影片。

## 安全設計
- 對戰中可看隊友和敵方（可關掉）；開「隱藏名稱」的玩家不分敵我都不查
- 對局詳細只顯示你和組隊隊友的名字
- 是否在對戰中是問本機 Riot Client，不會一直打 Riot 伺服器
- 不讀記憶體、不注入遊戲

這是用非官方端點做的個人工具，Riot 隨時可能更改。
